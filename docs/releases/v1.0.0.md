# Dream Reader 1.0.0

First independently branded Dream Reader release for Android ARM64.

## Download

Install `DreamReader-arm64-release.apk` on Android 8.0 or newer with an ARM64 Android userspace. Package: `com.dreamreader.app`. Version: `1.0.0` (build 1). This is a release-mode APK signed with Dream Reader's production key.

## Included

- Flutter Material 3 interface with five navigation tabs, five appearance presets, configurable Home sections, local reading statistics and library categories, layouts, sorting and filters.
- Live Keiyoushi repository synchronization and extension metadata, explicit trust consent, APK signer verification and a native compatibility runtime with source search, filters, chapter retrieval and source-aware image requests.
- Scrolling, webtoon, long-strip, paged, RTL and double-page readers, resume positions, bookmarks, volume controls and next-chapter prefetch.
- Background chapter downloads, multi-chapter selection, Wi-Fi constraints, pause/resume and offline reading.
- Checksum-verified backups, merge previews, current Mihon-format imports and scheduled backups to a selected Android storage folder.
- AniList/MyAnimeList client implementation with secure credential storage, title linking and explicit progress sync. Operator-owned public OAuth client IDs must be configured; no other app's credentials are embedded.

## Verification and current limits

Flutter analysis passed. Twenty-one automated test cases passed across the full suite and focused follow-up runs, including repository parsing, backup integrity/merge/settings validation, metadata round trips, tracking protocol tests and a 3,000-title/30,000-chapter SQLite fixture.

The APK independently passed ZIP integrity, ARM64-only architecture, application ID, release/not-debuggable, APK signature and 16 KB ZIP/ELF alignment checks.

**Device testing is assigned to the repository owner at their request.** Automated Android device tests have not passed: local software emulators were unstable, and CI encountered an AVD-location setup failure that is being repaired. Installation, release-mode extension execution, live reading/download journeys and scheduled-backup behavior are not claimed as device-verified in this release. Broad extension compatibility and phone performance remain unverified. Live tracker authorization and account writes also remain unverified without application registrations and a test account.

Extensions execute under Dream Reader's application UID. The separate process provides crash separation; it is not a security sandbox. Backup files include download metadata, not downloaded image files. Mihon multi-category assignments import as a combined category; tracker sessions and source credentials are not imported.

## Installation and updates

Download the APK and `SHA256SUMS` from this release. Verify the checksum, open the APK and allow installation from your chosen browser/file manager when Android asks. Review the repository disclosure at first launch. Dream Reader installs separately from StarReader and Mihon.

Future production updates use the same signing key and a higher build number. Export a backup before updating. CI verification APKs use disposable keys and cannot update this production installation.
