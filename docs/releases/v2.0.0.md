# Dream Reader 2.0.0

A refinement release focused on extension compatibility, a quieter reading interface, offline reliability and usable customization.

## Fixes for the reported extension problem

- Preserve Injekt's generic type information in optimized builds, addressing `TypeReference constructed without actual type information` during engine initialization.
- Preserve Zstandard APIs used by current KeiSource filter caches. The APK gate checks 1,030 actual class/member references from Atsumaru 1.6.26 and Kagane 1.6.42, plus generic type signatures.
- Show mixed-content sources, including Atsumaru and Kagane, without enabling the adult-only filter. Search ignores surrounding whitespace and searches extension and source names. Installed-source search links to catalogue results.

- Use Mihon's pinned native QuickJS runtime for JavaScript primitive results.
